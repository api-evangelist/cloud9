# Cloud9

> Cloud9 Esports, Inc. is a North American professional esports organization founded in 2013 by Jack and Paullie Etienne and headquartered in Santa Monica, California. Cloud9 publishes no developer program and no OpenAPI, but its website runs on WordPress and serves an anonymous, unauthenticated REST API covering its news, roster, teams and competitive record — and the same host quietly publishes an OAuth-gated Model Context Protocol server.

This file was generated by API Evangelist from the live Cloud9 public surface on 2026-08-09.
Cloud9 does not publish an llms.txt of its own (https://cloud9.gg/llms.txt returns 404).
Nothing here is documented by Cloud9; every endpoint below was probed directly.

## APIs

- [Cloud9 WordPress REST API](https://cloud9.gg/wp-json/): Anonymous, unauthenticated read access to the Cloud9 content estate. 277 routes across 14 namespaces; wp/v2 is the content contract.
- [Cloud9 MCP Server](https://cloud9.gg/wp-json/mcp/mcp-oauth-server): Remote Model Context Protocol server. OAuth 2.1 authorization code + PKCE, single `mcp` scope. Anonymous tools/list returns 401 — the tool list is not public.
- [Cloud9 Store JSON](https://store.cloud9.gg/products.json): Shopify storefront product catalogue, served anonymously.

## Content collections (anonymous GET, no key required)

- [Players](https://cloud9.gg/wp-json/wp/v2/players): 47 items — the Cloud9 roster.
- [Teams](https://cloud9.gg/wp-json/wp/v2/teams): 45 items — team pages across League of Legends, VALORANT, VALORANT Game Changers, Call of Duty, Rainbow 6, Counter-Strike, Rocket League, Halo, Super Smash Bros. Melee, Heroes of the Storm, London Spitfire, and streamers/content creators.
- [Achievements](https://cloud9.gg/wp-json/wp/v2/achievement): 564 items — the competitive record.
- [Case studies](https://cloud9.gg/wp-json/wp/v2/case-study): 7 items — partner activation case studies.
- [Posts](https://cloud9.gg/wp-json/wp/v2/posts): 89 items — news and announcements.
- [Pages](https://cloud9.gg/wp-json/wp/v2/pages): 17 items.
- [Media](https://cloud9.gg/wp-json/wp/v2/media): 1,175 items.
- [Categories](https://cloud9.gg/wp-json/wp/v2/categories): 19 items.
- [Search](https://cloud9.gg/wp-json/wp/v2/search): 769 indexed objects across all types.

## Conventions

- Pagination: `page` and `per_page` (max 100), with `X-WP-Total` and `X-WP-TotalPages` response headers and RFC 8288 `Link` relations.
- Field selection: `_fields` for sparse responses, `_embed` to inline linked resources, `context=view|embed|edit`.
- Schemas: HTTP `OPTIONS` on any collection returns its JSON Schema.
- Errors: `{"code": "...", "message": "...", "data": {"status": nnn}}` — not RFC 9457 problem+json.
- No rate-limit headers are returned and no rate-limit policy is published.
- No idempotency contract exists.
